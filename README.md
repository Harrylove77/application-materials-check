# 港新英申请材料终检

帮助申请香港、新加坡及英国院校的学生核对官网要求、整理附件，检查缺件及姓名、时间、文书逻辑风险。

## 使用

1. 下载仓库，将包含 `SKILL.md` 的整个文件夹放入所用 AI 工具的技能目录，或在会话中指定该文件。
2. 使用支持 Skills、联网检索和本地文件处理的 AI 工具，输入：

```text
请使用 $application-materials-check 整理我的申请材料。
院校与项目：学校全称 + 项目全称/官网链接
入学季与轮次：年份 + 入学季 + round（如已确定）
材料文件夹：你的材料路径
输出文件夹：你希望保存的路径
申请编号：如已有请提供
```

## 输出

- 按要求命名、合并、转换的 PDF 文件，保留原件。
- **直接出现在对话中的回执**，固定两部分：
  1. **材料检查表**：逐项说明要求、缺件、逻辑/名称/时间问题及处理建议。
  2. **提醒列表**：round 截止时间、电子送分、推荐人直传、录取后核验等，注明办理阶段。
- Markdown 回执备份及完整核对记录；仅在明确要求时生成回执 PDF。

## 运行条件

AI 工具负责检索与审读，脚本负责文件处理；本项目不是独立的院校爬虫。脚本需要 Python 3.10+：

```bash
python -m pip install -r scripts/requirements.txt
```

Word 等文件导出还需可用的本地 Office 或 LibreOffice。

公开仓库只放技能代码和说明，不上传学生材料、回执或个人信息。技能不会自动递交网申，也不会擅自改写证明或文书事实；查不到的官网规则会标为待核实。
