# 终检与风险

## 事实表

先逐件阅读，记录字段、原始写法、供比较的标准化值、文件/页码/段落、日期精度、本人陈述或机构证明、歧义。事实表发现矛盾，不能让模型代替学生裁定哪个版本是真的。

姓名基准可用身份证明或用户明确确认的申请英文姓名，目标名称以适用官网为准；证明错字也让出具方更正。不在回执重复证件号/生日/地址/第三方联系方式。姓名顺序、空格、简繁体、法定改名先判断可否解释，无护照须说明基准来源。

## 检查矩阵

| 维度 | 比较及应报告问题 |
|---|---|
| 目标名称 | 文书标题/正文/页眉页脚/文件名 vs 官网：错学校/校区/院系/学位，已更名项目；提及其他学校本身不必然串校 |
| 身份 | CV/文书/证明/申请表：无法由常见写法解释的姓名不一致，混入他人材料 |
| 教育 | 学位/在读/成绩单/CV：起止年份冲突，在读写成已获学位，专业或学位不符，预计毕业未注明 |
| 成绩 | GPA数值与分母、排名群体、百分制与四分制混用；不擅自换算或推断排名 |
| 实习 | CV/文书/证明的同一经历起止、单位、职位不同；在职证明签发早于结束日期不直接判错 |
| 时间 | 结束早于开始，未来写成已完成；重叠仅在全职/地点/工作量难兼容时记待解释 |
| 奖项研究 | 个人/团队、等级/年份/主办方不符，投稿称已发表；贡献夸大须有明确相反证据 |
| 语言考试 | 分数/日期冲突，按项目规定时点核有效性；不能一律推定两年或豁免 |
| 文书 | 漏必答题，硬性字数/页数不符，占位符/断句，前后论点明显矛盾；不打风格分 |
| PDF | 缺页，译文缺原文，印章/签字被裁，二维码模糊，旋转错，异常空白，修订批注残留 |

未取得申请表明确不覆盖该项交叉检查。没有证明写尚无佐证，不判造假。未完整读清不得称无逻辑问题。

## 风险记录

id, severity, certainty, title, evidence[], impact, action, output_ids, resolved。

- severity: blocker（无法满足已核验硬性要求）、high（错学校/身份/关键事实）、medium（需解释）、low（轻微可读性）。
- certainty: confirmed_conflict / needs_confirmation / unverified。
- evidence: file, locator, excerpt；确认冲突至少两处证据，或一处材料加一条官网要求。无证据只能列未核验范围。
- resolved仅在取得修正文件或明确有依据的解释后设true，保留解决依据，不因重命名/压缩成功而消失。

在材料检查表对应行列出缺件与风险，突出blocker/high；检查边界只在相关行或提醒简写，不新增回执模块。建议具体可执行，如“确认CV中的2025.07是否应为证明的2025.06，确定后仅修CV并重导”。

审读状态逐件记录：文件、页/段落覆盖、OCR/视觉/可提取文本、未读清范围、完成时间。inventory抽取成功不等于审读完成，脚本不能证明模型已经理解全部文件。
